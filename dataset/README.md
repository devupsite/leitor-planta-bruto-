# Dataset — Texturas do catálogo Bruto

Esta pasta não guarda os arquivos de imagem em si (ver regra 9 do `colaboracao.md` — nunca commitar binários grandes direto no Git).

Por enquanto, o viewer (Fase 0) usa cores/materiais placeholder gerados em código, sem depender de fotos reais do catálogo.

Quando as texturas reais entrarem:
- Armazenar em um serviço externo (Hugging Face Hub, Google Drive, Cloudflare R2, etc.)
- Documentar aqui o link de acesso e a convenção de nomes por produto
- Se o volume crescer, considerar Git LFS em vez de link externo
